# CivicAlert SEO setup

This project is configured for Google indexing with:

- homepage metadata and canonical URL
- robots.txt
- sitemap.xml
- social sharing metadata
- JSON-LD structured data

## Deploy checklist

1. Deploy to Vercel or your production domain.
2. Confirm the site loads at https://civicalert-sush.vercel.app/
3. Verify the URLs below return 200:
   - /robots.txt
   - /sitemap.xml
4. Submit the sitemap in Google Search Console.
5. Request indexing for the homepage in Search Console.
